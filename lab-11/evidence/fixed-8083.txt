==================== 1. SQL Injection: GET /rentals/search ====================
--- 1.1 Звичайний пошук: має знайти тільки одну оренду
REQUEST:  GET http://127.0.0.1:8083/rentals/search?reference=RENT-A-1795030224
RESPONSE: HTTP 200
[{"id":3,"reference":"RENT-A-1795030224","total":92000,"status":"Active"}]

--- 1.2 Payload ' OR '1'='1 : умова завжди true
REQUEST:  GET http://127.0.0.1:8083/rentals/search?reference=' OR '1'='1
RESPONSE: HTTP 200
[]

--- 1.3 Payload UNION: читаємо дані, яких API не віддає (користувач БД і версія)
REQUEST:  GET http://127.0.0.1:8083/rentals/search?reference=' UNION SELECT 0, current_user, 0, version() --
RESPONSE: HTTP 200
[]

==================== 3. Витік внутрішньої інформації ====================

REQUEST:  PATCH http://127.0.0.1:8083/rentals/3

{"code":"INVALID_REQUEST","message":"Некоректні дані ресурсу"}
